# SWRITE 2 — Release 0.1.0-rc1

Welcome to **Swrite 2 (Release Candidate 1)** — the calm, filesystem-first personal writing environment.

---

## 1. Core Highlights

- **Five Focused Studios:** Switch seamlessly between `WRITE`, `PLAN`, `DESK`, `EDIT`, and `PUBLISH` via `Mod+1` through `Mod+5`.
- **Zero Lock-In:** Your books and stories remain standard `.md` Markdown files in standard folders on your hard drive.
- **Distraction-Free Canvas:** Rich visual editing or raw Markdown Source mode with sub-millisecond typing latency.
- **Publication Isolation:** Export crisp PDF, DOCX, EPUB, and Markdown with zero style leakage from your active editor theme.
- **Atomic Reliability:** Background file watchers, conflict detection, crash recovery drafts, and local snapshot history.

---

## 2. System Requirements

- **Linux:** x86_64 / arm64 with GTK 3 & WebKitGTK 4.1.
- **macOS:** macOS 12 Monterey or later (Apple Silicon & Intel).
- **Windows:** Windows 10 / 11 (64-bit) with WebView2 runtime.

---

## 3. Getting Started

1. Launch Swrite.
2. Open an existing book folder or click **+ Create First Chapter**.
3. Write your story.
